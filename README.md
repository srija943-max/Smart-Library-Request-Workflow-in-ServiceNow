# Smart Library Request Workflow in ServiceNow

## Project Overview
Automated Library Request System built on ServiceNow platform to streamline book issuance and request tracking for students and librarians.

## Core Features
1. **Custom Tables:** Created `Book` (`u_book`) and `Borrow Request` (`u_borrow_request`) tables.
2. **Role-Based Access Control:** Configured `x_student` and `x_librarian` roles with proper ACL policies.
3. **Automated Approval Workflow:** Built a Flow Designer workflow for automated librarian approvals and status updates.
4. **Analytics:** Developed reports to track "Most Borrowed Books".
